# 研究所模擬面試

研究所模擬面試網站（v22.1），沿用原本 11 校題庫、Paper、語音練習與同步功能。

## v22.1：接續補漏與匯出修正

- 在 v22 基礎上補齊 89 道缺少完整參考答案的原題，連同改問版本修復 455 道受影響題目。2,744 道內建題目不再出現缺少完整答案的占位文字。
- 改問版本在顯示時繼承原題最新詳解；舊錯題與講義也重新取得最新內容，不改寫使用者原回答、收藏或掌握度。
- 練習提示與正式教授引導使用中文；保留必要的公式符號。八項句子層級提示另行整理，避免逐字替換造成語意不順。
- 白話定義增至 201 個。名詞卡與搜尋依大小寫區分 `PI`、`Pi`、`pI`、長度與濃度單位；`SEM` 與 `PI` 也依學科顯示對應意義。
- 圖解增至 58 組，新增八組針對原題及改問版本的教學：粒線體超氧探針、鈣離子與活性氧、粒線體含量、呼吸干預、滲透作用、逆流倍增、交互作用證據、表面標記。保留原有 50 組，未對應的題目不硬套圖解。
- PDF 使用瀏覽器列印／另存 PDF，明確提示選擇 PDF 與 A4；等待字型就緒，即使字型載入失敗仍可列印，並保留手動列印按鈕。彈出視窗受阻時提供處理提示。

此版的 54 項自動測試包含缺漏答案、改問繼承、舊紀錄、中文提示、縮寫意義、圖解配對、匯出內容與列印觸發，以及原有排程與同步測試。另以實際 DOM 檢查名詞搜尋，並將三題不同型態的講義轉為 A4 PDF 檢查中文、圖解與跨頁排版；不同瀏覽器的最終存檔對話框仍由使用者操作。

## v22：中文解說、機制圖與名詞提示

- 舊作答紀錄重新依目前題庫產生參考答案，不再直接顯示快取的中英混合版本。中文優先呈現，專業英文版由使用者自行展開。
- 詞組優先的翻譯字典，保留公式符號並提供對照，區分 `PI`、`Pi`、`pI`、微米與微莫耳濃度、統計與電子顯微鏡的 `SEM`，以及熱力學的 `RT`。
- 50 組人工整理的流程／機制圖、逐步原因、證據限制與自我檢查題。依題目與學科配對，未涵蓋題目不套入不相干流程。涵蓋數百筆核心題與相關變式；個人經歷和未提供內容的論文題不捏造固定答案。
- 114 個重點術語附白話定義，其他詞語提供中文對照；可用中英文查詢。練習題增加中文題意；正式模擬維持提示與答案隱藏。
- 首頁「圖解與白話名詞」可直接讀觀念，不建立作答紀錄。手機直向圖，桌面顯示流程／分支圖；比較圖不畫因果箭頭。
- 錯題講義帶入最新中文答案、原題圖表、機制圖、逐步說明、名詞表及追問。長題可自然跨頁，圖與單個步驟避免切斷，處理彈出視窗阻擋。

教學資料保存在 `content/learning-v22.json`。修改後執行 `node scripts/build-learning.cjs`，將資料嵌回單檔前端；不依賴外部翻譯或圖片服務。

## v21：掌握度與間隔複習

| 目前掌握度 | 下次安排 |
| --- | --- |
| 答錯／不會 | 10 分鐘後優先回流 |
| 需要補強 | 1 天後 |
| 大致會 | 3 天後 |
| 完全掌握 | 14 天後少量抽查，後續獨立完整作答可延至 30／60 天 |
| 待複核 | 手動複核後再安排 |

- 每題可手動確認掌握度。一次高分不會自動視為完全掌握；至少隔 24 小時、兩次無提示且評分信心足夠的完整回答才會自動進入完全掌握。舊紀錄缺少提示資訊時不推定已掌握。
- 原題與改問版本、不同校系的同一題共用進度。自由練習在到期弱題與新題之間分配；有其他候選題時，完全掌握題約占 5% 抽查。複習頁與收藏可主動提前練習。
- 正式模擬保持校系題型，必要時可抽尚未到期的題目以完成面試；同場不重複同一觀念。模擬中隱藏回饋與掌握度，結束後才顯示。
- 錯題清單與 PDF 以每個觀念的最新狀態為準，歷史回答仍保留。雲端合併依實際日期排序，分別保留較新的收藏與掌握度調整。
- 修正專項／錯題／指定教授練習的下一題、正式階段計時及 Paper 問答銜接，防止重複送出同一回答。

## 驗證

執行 `node --test tests/*.test.cjs`，不需要安裝套件。涵蓋排程、舊資料、同步衝突及完整程式的隔離流程測試；流程測試使用模擬 DOM，不會連到正式同步資料。

## 現有部署

Railway Function（原始碼保存於 `server/index.ts`）讀取 `app/index.html`，快取約 5 分鐘；更新 GitHub 後可用網站 `/?refresh=1` 重新載入來源。v21 同時修正強制重新整理仍取得 GitHub 舊快取的問題，並更新離線快取版本；沿用原有同步 API 與資料儲存。目前後端版本為 `22.1-web`，前端版本為 `22.1.0`。
