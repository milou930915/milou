# 研究所模擬面試

研究所模擬面試網站（v21），沿用原本 11 校題庫、Paper、語音練習與同步功能。

## v21：掌握度與間隔複習

| 目前掌握度 | 下次安排 |
| --- | --- |
| 答錯／不會 | 10 分鐘後優先回流 |
| 需要補強 | 1 天後 |
| 大致會 | 3 天後 |
| 完全掌握 | 14 天後少量抽查，後續獨立完整作答可延至 30／60 天 |
| 待複核 | 手動複核後再安排 |

- 每題可手動確認掌握度。一次高分不會自動視為完全掌握；至少隔 24 小時、兩次無提示且評分信心足夠的完整回答才會自動進入完全掌握。舊紀錄缺少提示資訊時不推定已掌握。
- 原題與改問版本、不同校系的同一題共用進度。自由練習在到期弱題與新題之間分配；有其他候選題時，完全掌握題約占 5% 抽查。複習頁與收藏可主動提前練習。
- 正式模擬保持校系題型，必要時可抽尚未到期的題目以完成面試；同場不重複同一觀念。模擬中隱藏回饋與掌握度，結束後才顯示。
- 錯題清單與 PDF 以每個觀念的最新狀態為準，歷史回答仍保留。雲端合併依實際日期排序，分別保留較新的收藏與掌握度調整。
- 修正專項／錯題／指定教授練習的下一題、正式階段計時及 Paper 問答銜接，防止重複送出同一回答。

## 驗證

執行 `node --test tests/*.test.cjs`，不需要安裝套件。涵蓋排程、舊資料、同步衝突及完整程式的隔離流程測試；流程測試使用模擬 DOM，不會連到正式同步資料。

## 現有部署

Railway Function 讀取 `app/index.html`，快取約 5 分鐘；更新 GitHub 後可用網站 `/?refresh=1` 重新載入來源。此版只更新前端，沿用原有同步 API 與資料儲存。API 的 `20-web` 是後端版本，前端版本為 `21.0.0`。
